The question

How do average real monthly earnings vary across Brazil’s federal units? How did earnings change compared with the same quarter a year earlier? The intended reader is an analyst comparing places and periods, not estimating an individual’s salary.

My contribution

This personal project combines extraction from IBGE SIDRA, a normalized dataset, coverage checks, a dashboard and an executive summary. This case study adds explicit SQL questions and a browser-based view so the analytical choices can be inspected before running the project.

Data and analytical decisions

The source is SIDRA table 6472, variable 5933. The grain is one federal unit per quarter. The committed extract is dated 15 August 2026 and spans Q2 2021–Q1 2026. This is a fixed historical snapshot, not a live feed or a claim to the latest available release.

State values must not be summed. The dashboard’s multi-state value is an unweighted mean of the selected federal units; it is not the official population-weighted national estimate. Year-over-year comparisons join the same quarter in the prior year rather than assuming four preceding rows always exist.

What this snapshot shows

For Q1 2026, the simple mean across all 27 federal units is BRL 3,437.41. Distrito Federal has the highest value (BRL 6,720.00) and Maranhão the lowest (BRL 2,240.00). These are descriptive observations from this snapshot, not causal explanations.

How to inspect the result

  1. Open the dashboard and select a quarter, region or state.
  2. Read the scope and comparison coverage alongside the metrics.
  3. Inspect the ranking and time series, then export the displayed rows.
  4. Run the SQL lab to reproduce coverage, ranking, regional means and exact year-over-year joins.

Power BI Desktop validation

The report was refreshed in Power BI Desktop 2.159.1231.0 on 4 November 2026. All 15 DAX checks passed. In Q1 2026 the Southeast slicer returned four federal units and a mean of BRL 3,971.50. With all regions selected in Q2 2021, the year-over-year card was blank because the snapshot has no prior-year observation for that quarter.

Limitations

No population weights, confidence intervals or causal model are supplied in this snapshot. Regional means describe their member states equally. Revisions to the underlying statistical series may change historical values. The data does not establish a company’s hiring outcomes or individual earnings.
